## 2. POLARIS Comparison Heuristic Mathematics

The system calculates contextual compatibility using inspectable multi-variable weights:

$$\text{Score}_{\text{POLARIS}} = \sum_{i} w_i \cdot s_i$$

Where:
- $w_{\text{var}} = 0.25$ (Variable / Subject Alignment)
- $w_{\text{loc}} = 0.25$ (Spatial Proximity & Sector Match)
- $w_{\text{temp}} = 0.20$ (Temporal Window Overlap)
- $w_{\text{method}} = 0.15$ (Methodological & Footprint Compatibility)
- $w_{\text{season}} = 0.15$ (Seasonal Observation Match)

## 3. Evidence Stress-Test Sensitivity Engine

When analyzing potential disagreement between findings $F_A$ and $F_B$:

1. **Sensitivity Quantification:** Computes variance gradient across spatial, temporal, seasonal, and methodological axes.
2. **Dominant Variable Identification:** Pinpoints the contextual attribute accounting for the maximum divergence in reported trends.
3. **Evidence Gap Formulation:** Formulates missing empirical constraints necessary to definitively resolve the uncertainty.
4. **Repository Linkage:** Discovers and links relevant NCPOR/MoES expedition datasets matching the gap parameters.
